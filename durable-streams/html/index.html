durable-streams Documentation

Durable Streams: the data primitive for the agent loop. A protocol and set of implementations for persistent, addressable, resumable event streams over plain HTTP — append-only logs with offset-based catch-up reads and live tailing (long-poll and SSE), exactly-once appends via idempotent producers, JSON mode with array flattening, and stream forking. A pnpm monorepo with a Go Caddy-plugin production server (memory, file, and bbolt stores), a TypeScript dev server, a Cloudflare Workers plus Durable Objects server, ten client libraries, and higher-level packages (Durable Proxy, Durable State, StreamDB, StreamFS, Yjs, AI SDK transports).
