Aha Moments

  1. One content model, two tables — Posts, pages, components, layouts all in data_tables + data_rows. No separate tables means simpler migrations and a unified data model.
  1. Three-layer publishing — Static bake (A) → LRU cache (B) → lazy holes (C). Most CMS systems use one approach; Instatic uses all three, automatically selecting the right one per page.
  1. No provider SDKs — AI drivers use raw fetch() calls. This eliminates SDK dependency churn and ensures all drivers share the same tool loop implementation.
  1. Plugin sandboxing — QuickJS-WASM in a Bun.Worker with capability permissions. A crash in one plugin doesn't take down the server, and network access is explicitly gated.
  1. React Compiler — No hand-written memoization. The compiler auto-memoizes, reducing boilerplate and eliminating a class of performance bugs.
  1. Machine-enforced bans — Banned dependencies aren't just documented; they're tested. Architecture tests fail if you import a banned package.
