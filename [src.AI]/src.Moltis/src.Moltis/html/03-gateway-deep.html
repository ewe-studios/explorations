Startup Sequence

  1. Directory overrides (lines 63-68):

``rust if let Some(dir) = config_dir { moltis_config::set_config_dir(dir); } if let Some(dir) = data_dir { moltis_config::set_data_dir(dir.clone()); } ``

  1. Auth resolution (lines 71-76):

``rust let token = std::env::var("MOLTIS_TOKEN").ok(); let password = std::env::var("MOLTIS_PASSWORD").ok(); let resolved_auth = auth::resolve_auth(token, password.clone()); ``

  1. Config loading (line 81):

``rust let mut config = moltis_config::discover_and_load(); ` Loads from moltis.toml, .yaml, or .json`.

  1. Memory probe (lines 90-91):

``rust let mut startup_mem_probe = StartupMemProbe::new(); startup_mem_probe.checkpoint("prepare_gateway.start"); ``

  1. TLS configuration (lines 94-100):
  • --no-tls flag overrides config
  • MOLTIS_BEHIND_PROXY env flag
  • MOLTIS_ALLOW_TLS_BEHIND_PROXY env flag
