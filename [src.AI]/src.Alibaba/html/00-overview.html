Page-Agent — AI-Powered Browser Automation Agent

Page-Agent is an AI agent that lives in your webpage and controls it with natural language. Built by Alibaba, it uses LLMs through OpenAI-compatible APIs to observe the DOM, reason about what to do, and execute actions like clicking, typing, scrolling, and navigating — all within a structured Re-act (Reasoning + Acting) loop. It runs entirely in-page as JavaScript; no Python, no headless browser, no screenshots required.

The Re-act Loop

Page-Agent's core is the Re-act (Reasoning + Acting) loop in PageAgentCore.execute():

flowchart TD Start["execute(task)"] --> Observe["👀 Observe<br/>getBrowserState() → flat DOM tree<br/>handleObservations() → warnings/URL changes"] Observe --> Assemble["Assemble Prompt<br/>System prompt + instructions<br/>+ agent_state + agent_history<br/>+ browser_state"] Assemble --> LLM["🧠 LLM Call<br/>invoke() with MacroTool<br/>tool_choice: AgentOutput"] LLM --> Parse["Parse Response<br/>evaluation_previous_goal<br/>memory + next_goal<br/>action: { toolName: input }"] Parse --> CheckDone{"action === 'done'?"} CheckDone -->|"yes"| Complete["✅ Task Complete<br/>return ExecutionResult"] CheckDone -->|"no"| Execute["Execute Tool<br/>MacroTool.execute(input)<br/>→ tool.execute.bind(this)(input, ctx)"] Execute --> Emit["Emit Events<br/>historychange (persistent)<br/>activity (transient UI)"] Emit --> IncStep["step++"] IncStep --> CheckMax{"step > maxSteps?"} CheckMax -->|"no"| Observe CheckMax -->|"yes"| Fail["❌ Max Steps Exceeded"]

Aha: The entire tool set is collapsed into a single "MacroTool" with a union schema. The LLM doesn't call individual tools — it calls ONE tool (AgentOutput) whose input contains both the reflection state AND the selected action. This forces the LLM to produce reflection (evaluation, memory, next goal) before every action, implementing the "reflection-before-action" mental model at the API level.

Key Design Decisions

  1. In-page JavaScript, not CDP. Page-Agent runs directly in the page context. This means it has full access to the DOM, can interact with JavaScript frameworks (React, Vue), and doesn't need Chrome DevTools Protocol or screenshots. The tradeoff: it can't interact with native browser UI (download dialogs, permission prompts).
  1. Text-based DOM, not screenshots. The PageController flattens the DOM into a textual representation of interactive elements (with index numbers), plus page metadata. This is cheaper (no vision model needed), faster (no image encoding), and more reliable (no OCR errors). The tradeoff: purely visual elements (decorative images, CSS-only layouts) are invisible to the agent.
  1. MacroTool enforces reflection. By merging all tools into one AgentOutput schema with required reflection fields, the architecture ensures the LLM evaluates the previous action, updates memory, and sets the next goal before choosing an action. This prevents the common failure mode where agents act without thinking.
  1. Events, not callbacks. The agent uses EventTarget with four event types (statuschange, historychange, activity, dispose) rather than callback props. This allows multiple listeners, clean teardown with removeEventListener, and decoupled UI updates.
  1. AbortController throughout. Every async operation — LLM calls, tool execution, wait() delays, onAskUser callbacks — receives the agent's AbortController signal. This enables cooperative cancellation: stop() calls abort(), and every pending operation checks signal.throwIfAborted().

Configuration Surface

// packages/core/src/types.ts:10-160
interface AgentConfig extends LLMConfig {
    language?: 'en-US' | 'zh-CN'       // UI and output language
    maxSteps?: number                    // Default: 40
    customTools?: Record<string, PageAgentTool | null>  // Extend or remove tools
    instructions?: {
        system?: string                 // Global system instructions
        getPageInstructions?: (url: string) => string  // Per-page dynamic instructions
    }
    stepDelay?: number                  // Default: 0.4 seconds between steps
    experimentalScriptExecutionTool?: boolean  // Enable execute_javascript tool
    experimentalLlmsTxt?: boolean       // Fetch /llms.txt from sites
    transformPageContent?: (content: string) => Promise<string> | string
    customSystemPrompt?: string         // Override entire system prompt
    // Lifecycle hooks
    onBeforeStep?: (agent, stepCount) => Promise<void> | void
    onAfterStep?: (agent, history) => Promise<void> | void
    onBeforeTask?: (agent) => Promise<void> | void
    onAfterTask?: (agent, result) => Promise<void> | void
    onDispose?: (agent, reason?) => void
}
