Fetch Proxy

Source: packages/fetch-proxy/src/lib/fetch-proxy.ts

Creates a fetch function that forwards requests to another server, rewriting cookies and headers.

export interface FetchProxyOptions {
  fetch?: typeof globalThis.fetch          // Custom fetch implementation
  rewriteCookieDomain?: boolean            // Default: true
  rewriteCookiePath?: boolean              // Default: true
  xForwardedHeaders?: boolean              // Default: false
}

export function createFetchProxy(target: string | URL, options?: FetchProxyOptions): FetchProxy

URL Rewriting

// Proxy: /search?q=remix → https://remix.run/search?q=remix
// Proxy: / → https://remix.run/dest
// Proxy: /search?q=remix → https://remix.run/dest/search?q=remix

The proxy appends the incoming request's pathname and search to the target URL.

Cookie Rewriting

// Response Set-Cookie: session=abc; Domain=remix.run; Path=/dest/users
// Rewritten to:           session=abc; Domain=incoming.com; Path=/users
  • Domain rewrite: Changes Domain from target domain to incoming request domain
  • Path rewrite: Strips the target's pathname prefix from the cookie's Path

X-Forwarded Headers

createFetchProxy('https://api.example.com', { xForwardedHeaders: true })
// Adds:
// X-Forwarded-Proto: https
// X-Forwarded-Host: incoming.com

Request Forwarding

Method, headers, and body are all forwarded from the incoming request.

export interface LazyFile {

Request Conversion

Converts Node.js IncomingMessage to standard Request:

function nodeRequestToWebRequest(req: IncomingMessage): Request {
  const url = `http://${req.headers.host}${req.url}`
  return new Request(url, {
    method: req.method,
    headers: new Headers(req.headers as Record<string, string>),
    body: req.method !== 'GET' && req.method !== 'HEAD' ? req : undefined,
  })
}

Response Conversion

Converts Response to Node.js ServerResponse:

function webResponseToNodeResponse(response: Response, res: ServerResponse): void {
  res.statusCode = response.status
  res.statusMessage = response.statusText

  for (const [name, value] of response.headers) {
    res.setHeader(name, value)
  }

  if (response.body) {
    response.body.pipeTo(new WritableStream({
      write(chunk) { res.write(chunk) },
      close() { res.end() },
    }))
  } else {
    res.end()
  }
}

TAR Parser

Source: packages/tar-parser/src/lib/tar-parser.ts

Streaming TAR archive parser.

export interface TarEntry {
  name: string
  size: number
  mode: number
  mtime: Date
  type: 'file' | 'directory' | 'symlink'
  body: ReadableStream<Uint8Array>
}

export function parseTar(stream: ReadableStream<Uint8Array>): AsyncIterableIterator<TarEntry>

Each entry's body is a ReadableStream — file contents are streamed, not buffered. Used for unpacking deployment archives and package distributions.

TAR Format

Parses both ustar (POSIX) and GNU TAR formats. Handles:

  • File entries (regular files)
  • Directory entries
  • Symlink entries
  • Long filenames (GNU extension)
