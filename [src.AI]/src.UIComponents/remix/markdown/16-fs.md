# FS: File System Integration

`@remix-run/fs` wraps Node.js `fs` to produce streaming `File` objects with lazy content loading.

Source: `packages/fs/src/lib/fs.ts` — 60+ lines.

## openFile

```typescript
export function openFile(filename: string, options?: OpenFileOptions): File {
  let stats = fs.statSync(filename)

  if (!stats.isFile()) {
    throw new Error(`Path "${filename}" is not a file`)
  }

  let content: LazyContent = {
    byteLength: stats.size,
    stream(start, end) {
      return streamFile(filename, start, end)
    },
  }

  return new LazyFile(content, options?.name ?? filename, {
    type: options?.type ?? detectMimeType(filename) ?? '',
    lastModified: options?.lastModified ?? stats.mtimeMs,
  }) as File
}
```

### What It Does

1. `fs.statSync` gets file metadata (size, mtime)
2. Creates a `LazyContent` interface — **no file content is read yet**
3. Wraps in `LazyFile` (from `@remix-run/lazy-file`) — a `File` that streams on demand
4. Auto-detects MIME type from extension using `@remix-run/mime`

### OpenFileOptions

```typescript
export interface OpenFileOptions {
  name?: string          // Override filename (default: actual filename)
  type?: string          // Override MIME type (default: detected from extension)
  lastModified?: number  // Override timestamp (default: fs mtime)
}
```

## streamFile

```typescript
function streamFile(
  filename: string,
  start = 0,
  end = Infinity,
): ReadableStream<Uint8Array<ArrayBuffer>> {
  let readStream = fs.createReadStream(filename, { start, end: end - 1 }).iterator()

  return new ReadableStream({
    async pull(controller) {
      let { done, value } = await readStream.next()
      if (done) {
        controller.close()
      } else {
        controller.enqueue(value)
      }
    },
  })
}
```

Converts Node.js `ReadStream` to a `ReadableStream<Uint8Array>` using the async iterator protocol. The `end` parameter is exclusive (matching `Blob.slice()` semantics), while `fs.createReadStream` uses inclusive `end`, hence `end - 1`.

Aha: The file is never fully loaded into memory. `openFile` returns immediately after `statSync` — the actual file content is only read when `.stream()` is called. This enables serving large files (videos, archives) without buffering them.
