performativeUI: Overview

A React component library of 32 components and 4 hooks for "performative" AI-startup landing page patterns. Components are canvas-rendered (NodeGraphBackground, AsciiHero, Goldeneye, Aurora), DOM-animated (WordRoll, Rotator, SlippyWords), or CSS-driven (GradientText, GlassCard, Sparkle). Ships as a library with a docs site.

Source: https://github.com/[...]/performativeUI Location: /home/darkvoid/Boxxed/@formulas/src.rust/src.AI/src.UIComponents/performativeUI/

Quick Start

npm install performative-ui

import { NodeGraphBackground, Prompt, Temperature } from 'performative-ui'

Or from source:

cd performativeUI
npm install
npm run dev        # Vite docs site
npm run build      # Library build

Architecture

flowchart LR subgraph Canvas["Canvas Components"] A["NodeGraphBackground\n270 lines, particle sim"] B["AsciiHero\n101 lines, uses useAsciiField"] C["Goldeneye\n187 lines, spiral math"] end subgraph Text["Text Animations"] D["WordRoll\n102 lines, slot-machine"] E["Rotator\n76 lines, 3D transform"] F["SlippyWords\n149 lines, stagger"] G["QuestText\n123 lines, RPG reveal"] end subgraph UI["UI Components"] H["Prompt\n268 lines, textarea + toolbar"] I["MockIDE\n170 lines, token typing"] J["Temperature\n451 lines, canvas ripple"] end subgraph Hooks["Headless Hooks"] K["useAsciiField\n265 lines, canvas ASCII"] L["useTypewriter\n92 lines, char-by-char"] M["useCounter\n39 lines, animate"] N["useTokenStream\n83 lines, burst"] end

Aha: The library uses a consistent pattern: every component is forwardRef-ed with ComponentPropsWithoutRef<"element"> extension, meaning it accepts all native element props plus its own. The cn() utility (clsx + tailwind-merge) is used everywhere for className merging. Canvas components (NodeGraphBackground, AsciiHero) use requestAnimationFrame loops with cleanup on unmount.
