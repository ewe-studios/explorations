# next-maps Documentation

Full-screen interactive Mapbox GL map with search, custom markers, popups, and 5 switchable styles. Built on Next.js 15 with App Router, Tailwind v4, and shadcn/ui.

| Attribute | Value |
|-----------|-------|
| Source files | ~36 (src/) |
| Framework | Next.js 15.2.3 + Turbopack |
| Map SDK | Mapbox GL JS 3.10.0 |
| React | 19.0.0 |
| CSS | Tailwind v4 + oklch tokens |
