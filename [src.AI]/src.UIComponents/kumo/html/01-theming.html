kumo Theming: CSS light-dark() Over dark:

Kumo uses CSS light-dark() for automatic theme handling instead of Tailwind's dark: variant. This is enforced by a custom ESLint plugin.

Source: /home/darkvoid/Boxxed/@formulas/src.rust/src.AI/src.UIComponents/kumo/packages/kumo/

CSS Import

import "@cloudflare/kumo/styles";
// or for non-Tailwind projects:
import "@cloudflare/kumo/styles/standalone";

Tailwind CSS v4 Setup

/* Your CSS file */
@source "../node_modules/@cloudflare/kumo/dist/**/*.{js,jsx,ts,tsx}";
@import "@cloudflare/kumo/styles/tailwind";
@import "tailwindcss";

Import order matters — kumo's @theme tokens must be registered first.

Semantic Tokens

All colors use semantic tokens, never raw Tailwind colors:

TokenPurpose
`bg-kumo-base`Background base
`text-kumo-default`Default text color
`text-kumo-strong`Strong/emphasized text
`text-kumo-subtle`Muted text
`bg-kumo-tint`Tinted background
`ring-kumo-line`Border/ring color
`ring-kumo-focus`Focus ring
`ring-kumo-brand`Brand-colored ring
`ring-kumo-danger`Danger-colored ring

light-dark() Function

/* Generated by theme codegen */
--kumo-base: light-dark(#ffffff, #1a1a1a);
--kumo-text: light-dark(#1a1a1a, #ffffff);
--kumo-line: light-dark(#e5e5e5, #333333);

The browser resolves light-dark(light, dark) automatically based on the system or document theme.

No dark: Variant

Enforced by lint/no-tailwind-dark-variant.js ESLint plugin.

// WRONG — dark: variant is banned
<div className="bg-white dark:bg-black" />

// RIGHT — semantic tokens handle theme automatically
<div className="bg-kumo-base" />

Aha: This eliminates the need for separate dark mode styling. Every component automatically adapts when the theme changes because the CSS custom properties resolve to different values.

Button Emphasis Colors

/* Primary button */
--kumo-button-emphasis-bg: color-mix(in oklch, var(--color-kumo-brand), white 30%);
--kumo-button-emphasis-ring: color-mix(in oklch, var(--color-kumo-brand), black 10%);

/* Destructive button */
--kumo-button-emphasis-bg: color-mix(in oklch, var(--color-kumo-danger), white 30%);
--kumo-button-emphasis-ring: color-mix(in oklch, var(--color-kumo-danger), black 10%);

Uses CSS color-mix() for dynamic color generation — no separate color variables needed.

Theme Generation

Source: scripts/css-build.ts

Builds CSS output from design tokens. Two modes:

  • Tailwind mode — @import "@cloudflare/kumo/styles/tailwind" — uses Tailwind's @theme directive
  • Standalone mode — @import "@cloudflare/kumo/styles/standalone" — pre-compiled CSS with all utilities

cn() Utility

// src/utils/cn.ts
import { clsx } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}

Merges Tailwind classes, resolving conflicts (e.g., bg-red-500 + bg-blue-500 → bg-blue-500).
