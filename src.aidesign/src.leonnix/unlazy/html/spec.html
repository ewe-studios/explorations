unlazy is an agent skill. It changes what an autonomous agent must do before it may report that substantial work is complete. The agent writes a gate ledger first. Each gate states one observable outcome. A runnable gate carries a CHECK: command and an EXPECT: string. A checker runs the command and records evidence. A completed gate counts as met only when the process exits zero, the expectation matches, and the stored evidence binds the current gate definition. The optional Stop hook blocks the agent from ending a coding session while the resolved ledger still has unmet gates or unfinished dispatch waves.

2. Scope

The exploration reads the source at the pinned commit. It explains the instruction layer, the strict ledger format, the checker and its evidence model, the approval boundary, the shared file-reading and file-writing primitives, the lease and dispatch coordination, the Stop hook and installer, the quality linter, the templates, the test suite, and the continuous integration matrix.

It does not run the checker, the hook, the installer, the linter or the tests. It does not approve or execute any CHECK: command. It does not judge whether the method improves agent output. Where the source states a value, the exploration quotes the value and the line. Where the source does not state a value, the exploration says so.
