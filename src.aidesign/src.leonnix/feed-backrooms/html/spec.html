FEED is a first-person horror game set in the Backrooms. The player is the monster. Eight people enter the building. The player must catch all eight before hunger runs out. The game is built from nine JavaScript modules, one HTML page and 26 texture images and 38 sound files.

The repository has five commits. The first commit holds the game. The other four add phone support, the Vercel build settings, a link in the README and Vercel Analytics.

2. Scope

The exploration reads the source at the pinned commit. It explains the level generator, the baked light grid, the shared material patch, the prey state machine, the procedural people, the monster arms, the post-processing stack, the audio system and the trailer recorder.

It does not run the game, build the bundle, deploy the site, or play the trailer. It does not judge visual quality. Where the source states a value, the exploration quotes the value and the line. Where the source does not state a value, the exploration says so.
