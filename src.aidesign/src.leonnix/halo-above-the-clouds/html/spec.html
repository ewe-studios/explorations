halo-above-the-clouds is a real-time Three.js scene and a 45 second drone film. A concrete ring restaurant stands between snowy dolomite pinnacles above a sea of clouds. The same code base serves two outputs. A browser opens index.html and draws the scene live. A headless Chrome process renders 1,350 frames and encodes the film.

The tree holds 9,780 lines in 55 tracked files. The source is 12 JavaScript scene modules (4,345 lines), five GLSL modules (3,421 lines), 27 tool scripts (4,858 lines), and seven root files. The four docs/ files are JPEG images for the README page.

The repository has two commits. The first adds the scene, the film and the tools. The second fixes the README facts, skips the matte when no data exists, and repairs key handling.

2. Scope

The exploration reads the source at the pinned commit. It explains the renderer bootstrap, the configuration, the terrain level pipeline, the far-field terrain key, the sky bake, the cloud raymarch, the ring structure, the lights, the camera timeline and views, the post chain, the film render driver, the graphics processing unit (GPU) lock, the film checker, and the data fetch.

It does not run the scene, render a frame, encode the film or download data. It does not judge the visual result. Where the source states a value, the exploration quotes the value and the line. Where the source does not state a value, the exploration says so.
