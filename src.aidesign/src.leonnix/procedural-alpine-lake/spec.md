`procedural-alpine-lake` is a 60 second cinematic flight through an alpine lake valley. Every
surface and every sound is generated by code. The tree holds no texture, mesh, environment map
or audio sample. The images under `docs/` exist only for the README page.

The renderer is 13,790 lines of Python and 14,444 lines of OpenGL Shading Language (GLSL). The
documentation calls the language "GLSL" after this first use.

The repository has three commits. The first holds the renderer, the world bake and the
soundtrack. The second adds ten reference photographs to the README. The third adds the prompt
that started the work.

## 2. Scope

The exploration reads the source at the pinned commit. It explains the analytic terrain, the
GPU erosion simulation, the hand-placed waterfall and inflow stream, the baked world cache, the
split ray-marching renderer, the procedural forest, rocks, ground cover, water and sky, the
camera path search, the finishing pipeline, the nature sound bed, the orchestral score and the
final render driver.

It does not run the renderer, bake the world, render a frame or play the soundtrack. It does not
judge the visual result of the film. Where the source states a value, the exploration quotes the
value and the line. Where the source does not state a value, the exploration says so.
