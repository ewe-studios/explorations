Shanshui means "mountains and water". The package paints ten Chinese ink-wash landscapes in code. No image, font or audio sample is loaded at runtime. WebGL 2 shaders and Canvas2D brushwork produce every cliff, pine, mist bank, crane, ripple and snowflake. JavaScript synthesizes the soundtrack sample by sample. One clock drives the picture and the sound.

The film is 60 seconds long at 60 frames per second and 1920 by 1080 pixels. It holds ten paintings, two bars of music each at 80 beats per minute. Every seam is centred on a bar line. The ten paintings are ordered for the film, not by scene number: bamboo valley, cranes over the falls, rope bridges, floating peaks, red cascade, autumn ruins, golden river, stone bridge, moon over the lake, and snow temple.

2. Scope

This package covers shanshui as a system. It covers these areas:

  • The visual idea: ink on warm rice paper, three depth planes, a value ladder, edges, trees,

water and a sparing red accent.

  • The engine: a 2.5D camera, flat cards at depth, three layer kinds, premultiplied alpha,

reflections, wind sway, bakes and the shared GLSL library.

  • The painting library: brush, ink effects, pine, rock, peaks, atmosphere, water, architecture,

fauna, flora and the seal.

  • The ten scenes: composition, layers, camera move, animation and per-scene helpers.
  • The transitions: bloom, mist, cloud rise, spray, wind, scroll, sun match, dusk, snow and

evaporate.

  • The clock: 80 beats per minute, four beats per bar, two bars per painting, 20 bars in 60

seconds, and named sound cues.

  • The sound: a guzheng, xiao flute, singing bowl, wind and water, synthesized from samples.
  • The tools: live server, warm render daemon, still and comparison tool, contact sheets, film

renderer, frame forensics and documentation generator.

  • The film path: sub-frame motion blur, GPU YUV conversion, WebSocket streaming and ffmpeg.

It does not run shanshui. It does not start the server, open a browser, render a frame, play the film, generate the soundtrack or build a scene. All runtime numbers come from the project documents and are marked as not verified.

10. Corrections and limits found during research

The inventory matched: pin b5357c0, 146 tracked files, version 1.0.0, MIT. The following findings qualify the first reading.

  1. The film is not in the repository. README.md:9 says the film is attached to the

releases. git ls-files holds no .mp4 file and no video/ folder. The render path is defined by tools/render.mjs. The output does not ship.

  1. The reference paintings are not in the repository. README.md:64 and

docs/ENGINE.md:3 refer to ref/01.webp to ref/10.webp. The folder is absent. The comparison options need images that the reader must supply.

  1. The soundtrack is not in the repository. README.md:41 tells the reader to run

tools/audio.mjs and write out/audio/soundtrack.wav. No .wav file is tracked and out/ is ignored (.gitignore:2).

  1. All render output is absent. out/ is ignored. The contact sheet docs/stills.jpg is the

only picture in the checkout. It is documentation, not a render input.

  1. One transition duration differs between the guide and the timeline. docs/FILM.md:17

gives the wind wipe as 1.6 seconds. src/timeline.js:24 sets the autumn ruins transition to 2.0 seconds with the wind type. The timeline is the executable value.

  1. The spray transition centres differ between the guide and the timeline. docs/FILM.md:37

assumes the s09 waterfall at (330, 560) and the s08 cascade at (700, 420). src/timeline.js:23 passes c: [308, 672] and c2: [640, 270]. The timeline is the executable value.

  1. The sun-match centres differ between the guide and the timeline. docs/FILM.md:38

assumes s02 at (1520, 330) and s05 at (1700, 345). src/timeline.js:26 passes c: [1349, 308] and c2: [1742, 353].

  1. The no-assets claim has one qualification. The runtime loads no image, font or audio

sample (docs/ENGINE.md:3-4). The README displays docs/stills.jpg, and the comparison tools read ref/ images. Neither is a render input.

  1. There is no build step. package.json has no build script. index.html loads the

modules directly. Vite is absent.

  1. The dependencies do not include a browser. puppeteer-core connects to an installed

Chrome or Edge. The README states this at README.md:45. npm install installs the client only.

  1. The Node version is a README statement. README.md:45 states Node 20 or later.

package.json has no engines field, so the version is not enforced.

  1. The film has no tracked output or duration proof. The 60 second duration comes from

src/timeline.js:9. No encoded file verifies it.
