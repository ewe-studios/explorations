Valle Morta is a first-person zombie survival shooter that runs in a browser. The
setting is a war-ruined alpine valley. Every visual asset is generated by code in
the repository: the terrain, the village, the church, the bridge, the river, the
grass, the trees, the tank wreck, the rifle, the infected and 22 physically based
rendering (PBR) texture sets. No premade model or texture is used. The sound
effects and the music are licensed third-party recordings.

## 2. Scope

This package covers the game as a system. It covers these areas:

- The engine: the high dynamic range (HDR) renderer, the ray-marched cloud sky,
  the cloud-shadow map, height fog, ambient occlusion, bloom and tone mapping.
- The world: erosion-simulated terrain, the clipmap, the far mountain mesh,
  procedural buildings, the bridge, vegetation, water and props.
- The game: the player controller, the rifle, the infected artificial
  intelligence (AI), the flow-field navigation, the per-bone hit volumes, the
  wave director, the abilities, the effects and the audio.
- The UI: the heads-up display (HUD), the minimap and the settings.
- The offline tools: terrain bake, texture generation, Blender scripts, capture,
  performance measurement and playtest.
- The cinematic: one 45-second scripted film at 3840 by 2160, 24 frames per second,
  in HDR10.
- The quality record: `docs/DESIGN.md`, the README limitations and the credits.

It does not run the game. It does not open a browser, start Vite, run a generator,
launch Blender, or render the film. It does not listen to the audio.

## 10. Corrections and limits found during research

The inventory matched: pin `64471ca`, 524 tracked files, MIT licence file,
version 1.0.0. The following findings qualify the first reading.

1. **The licence field is stale.** `package.json:14` says ISC. `LICENSE:1` says
   MIT, and `README.md:71` says MIT. The package follows the file and the README.
2. **The audio is not MIT.** The music is CC BY 4.0. Six sounds are CC BY 3.0:
   three roll sounds and three hard-landing sounds. The rest are CC0
   (`README.md:65`, `public/assets/audio/CREDITS.md:88-97`). The credits file is
   the record.
3. **The README audio limit is stale.** `README.md:61` says there is no church
    bell recording and no wood-footstep sound. The checkout has `bell_toll.mp3`
    and four `step_wood` files, and the game preloads and plays them
    (`src/game/game.js:276`, `src/game/game.js:378`,
    `public/assets/audio/CREDITS.md:132`, `public/assets/audio/CREDITS.md:94-97`).
4. **The CC0 claim is too broad.** `README.md:65` says all non-music sounds are
    CC0. Six roll and landing sounds are CC BY 3.0
    (`public/assets/audio/CREDITS.md:88-97`).
5. **The head-shot claim is too broad.** `README.md:31` says head shots kill.
    `src/game/zombies.js:674` forces a kill only when the type has 100 health or
    less. A head shot from the rifle does not kill a brute or a boss.
6. **Most tools are generated model parts, not scripts.** 155 of the 250 tool
   files are under `tools/weapon/`, and 52 are under `tools/zombie/`. The root
   tools are 10 files.
7. **The public folder is mostly audio.** 133 of 225 public files are audio.
   The generated models are 15 files, and the terrain data is 9 files.
8. **The game is one page.** `index.html` and `src/main.js` start a Vite
   application. There is no server component.
9. **The film is not a separate renderer.** `src/cinematic/film.js` and
   `cinematic/capture.mjs` drive the live game and capture it. The film is not a
   second scene.
10. **No runtime claim is verified.** No frame was rendered, no wave was played,
   and no generator was run.
11. **The package has no test suite.** The tools are generators and capture
   helpers. `tools/playtest.mjs` automates a play session but is not a unit test.
12. **The design document is short.** `docs/DESIGN.md` holds rules, controls and
   contracts in 1,277 words. It does not describe every module.
13. **The texture count is 22 PBR sets, not 68 files.** `README.md:5` states 22
    sets. The public tree holds 68 texture files, so a set has several maps.
14. **The `far` quality field is unread.** All four presets define `far`
    (`src/engine/engine.js:10-13`). No file under `src` reads it. The package
    records the field but cannot say what it changes.
