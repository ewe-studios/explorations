2. Scope

This exploration covers every project in the container. Each project explains what it is, how it is built, the mechanism that carries its idea, and the limits that its own files state.

It does not run the projects, render their output, or publish their packages. It reads the source and the documents at the pinned revision.

3. Depth: every package is detailed

Every package receives the full exploration. Depth does not follow size. A nine-file skill still gets its architecture, its mechanism, its workflow, and its limits, because a reader who opens that package must be able to learn how it works from the package alone.

LevelDocuments per packageWords per deep diveSnippets per deep dive
Every package6 (README plus five deep dives)3,000 to 5,00010 or more

The five deep dives are always 00-overview, 01-architecture, 02-core-mechanism, 03-workflow-and-quality, and 04-limits-and-comparison. A small project divides a small surface into those five parts. It does not receive a shorter list.

Every deep dive has at least two Mermaid diagrams, at least one Aha: insight, and ten or more byte-exact snippets with a path:line citation header. The README has the thesis, one Mermaid map, the document table, the reading order, and the non-claims. Each document expands every abbreviation at first use.

The size bands in section 4 now set only the order of work. They do not set depth.

5. Constraints

  • Aerospace and Defence Simplified Technical English (ASD-STE100) applies to every sentence.
  • Each document cites its source with path:line and quotes code byte for byte.
  • A document states when its source does not define a value. It does not guess.
  • One package is in flight at a time. At most four subagents work on that one package. A new

package does not start until the current one is committed and pushed.

  • The fresh-reader review runs for each package. A fresh agent reads the package documents with no

memory of the writing, no tools beyond reading, and no web access. The writer fixes every reported gap before the package is done.
