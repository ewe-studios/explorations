Durable Execution -- Index

A reader's guide to the Resonate durable-execution engine in code/final/ — the ~5,500-line Python runtime behind "Durable Execution in 5,000 Lines." The documents are ordered as a course: start at 00 and follow the Continue to footer, or jump to any piece. Each teaches its key idea in the first paragraph, shows the real code, and names the source file it is reading.

The whole design is three claims and one rule, and every document is a consequence of them:

  1. The kernel does no I/O — a pure function from a document, a request, and an instant to effects

and a reply.

  1. Everything outside is two ports — four store operations, two queue operations.
  2. Cloud Tasks pushes, so a worker is an endpoint — no loop waits for work.

And the one rule the arrows do not show: arm the deadline → commit → disarm the old → send.
