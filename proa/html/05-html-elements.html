05 -- HTML Elements and Escaping

The element layer turns a tag, a set of attributes, and a child closure into bytes. It is the first layer above the buffer that knows HTML. The key idea is that escaping is a policy, not a list of replace calls. One sealed policy decides HTML versus XML, text versus attribute, and raw-text sentinel masking.

The Tag Table

Tag (proa_core/src/shared/tag.rs) is an enum of about 130 HTML, SVG, and Web Component elements. It exposes three facts per variant: as_str, is_void, and mode.

// proa/proa_core/src/shared/tag.rs:353
pub fn is_void(self) -> bool {
    matches!(
        self,
        Tag::Area | Tag::Base | Tag::Br | Tag::Col | Tag::Embed | Tag::Hr
            | Tag::Img | Tag::Input | Tag::Link | Tag::Meta | Tag::Param
            | Tag::Source | Tag::Track | Tag::Wbr
            // SVG void elements
            | Tag::Path | Tag::Circle | Tag::Rect | Tag::Line | Tag::Ellipse
            | Tag::Polyline | Tag::Polygon | Tag::Stop | Tag::Use | Tag::Image
            | Tag::Animate | Tag::AnimateMotion | Tag::AnimateTransform | Tag::Set
    )
}

is_void distinguishes self-closing elements. mode returns ContentMode::Script for Tag::Script, ContentMode::Style for Tag::Style, and ContentMode::Html otherwise. The Elem renderer uses this to switch escaping when it descends into a script or style child.

The byte strings are precomputed at compile time by a macro. open_bytes returns b" and close_bytes returns b"", both baked into the read-only section. AttrKey does the same with attr_open_bytes (b" name=\"") and attr_bare_bytes (b" name"). Because they are &'static [u8], they flow into extend_static and become zero-copy Part::Static entries on ZeroCopyBuf. The buffer connection is in 04-write-buf.md.

Elem: Normal and Void

Elem (proa_core/src/shared/elem.rs) wraps a tag, an inline attribute list, and a child closure. It is generic over a Kind marker, Normal or Void.

// proa/proa_core/src/shared/elem.rs:30
pub struct Elem<'a, Kind, const N: usize, B: WriteBuf, F, L: DataLoader = NoLoader>
where
    F: FnOnce(&mut WebContext<L, B>) -> Result<(), WriteError>,
{
    tag: Tag,
    attrs: InlineVec<Attr<'a>, N>,
    child: F,
    _kind: PhantomData<Kind>,
    _buf: PhantomData<fn(B)>,
    _loader: PhantomData<fn(L)>,
}

Attributes use heapless::Vec, an inline buffer, so a small element carries no heap allocation. The constructors are el for normal elements and void for void elements. Each debug_asserts that the tag kind matches. A normal element renders open tag, child, close tag. A void element renders only the open tag.

Attributes

Attr (proa_core/src/shared/attr.rs:796) has three shapes.

// proa/proa_core/src/shared/attr.rs:796
pub enum Attr<'a> {
    Str { k: AttrKey, v: &'a str },
    Bool { k: AttrKey, present: bool },
    Data { name: &'a str, v: &'a str },
}

Str is a normal name and value. Bool renders a bare attribute only when present is true. Data is a data-* attribute with a free-form name. validate checks that a Data name starts with data-, has at least one character after it, and contains no ASCII uppercase.

write_attr routes each shape. For Str, it first checks the URL policy. If the key is_url_attr() and has_dangerous_url_scheme(v) is true, it emits an empty attribute and a debug assertion fires. Otherwise it emits the name, escapes the value, and closes the quote.

// proa/proa_core/src/shared/attr.rs:547
pub fn is_url_attr(self) -> bool {
    matches!(
        self,
        AttrKey::Href | AttrKey::Src | AttrKey::Action | AttrKey::Formaction
            | AttrKey::Poster | AttrKey::Ping | AttrKey::Cite | AttrKey::ObjectData
            | AttrKey::Background | AttrKey::Longdesc | AttrKey::Manifest
    )
}
