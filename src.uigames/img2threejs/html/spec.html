2. Scope

This exploration explains how img2threejs turns one reference image into a TypeScript Three.js factory. It covers the two halves of the product: the agent-facing skill contract and the deterministic Python forge. It covers the installer, the five forge stages, the gate system, the reference library, the optional integrations, the test and release machinery, and the limits that the project states about itself.

It does not cover the hosted demo gallery, the paid rendering services that plugins can call, or the Three.js library itself.
