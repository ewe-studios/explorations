Tauri Ecosystem Documentation

Comprehensive documentation for the Tauri desktop application ecosystem. Six major Rust crates plus a plugin system, covering the full stack from application framework to WebView rendering to window management.

Foundation

  • Overview — What Tauri is, architecture at a glance, crate dependency graph

Core Deep Dives

  • Tauri Core — App, Builder, AppManager, WindowManager, WebviewManager, plugin system, state management, Runtime trait, generate_context! macro
  • IPC and ACL — #[tauri::command] macro, capability files, scoped permissions, IPC transport layers, event system, invoke handler composition
  • Build and CLI — tauri dev, tauri build, tauri-build code generation, tauri-bundler pipeline (DMG/MSI/NSIS/AppImage/deb/rpm), icon generation

Platform Libraries

  • Wry WebView — WebViewBuilder (50+ fields), 4 platform backends (WKWebView, WebView2, WebKitGTK, Android WebView), protocol handlers, initialization scripts
  • Tao Windowing — EventLoop, Window (60+ methods), ControlFlow, 5 platform backends, raw window handles, DPI awareness, multi-monitor

UI and Layout

  • Taffy Layout — TaffyTree, Flexbox/Grid/Block algorithms, 9-slot measure cache, no_std support, LayoutTree trait
  • Dioxus UI — VirtualDom, rsx! macro, WriteMutations trait, signals, hooks, desktop renderer (tao+wry), cross-platform rendering

Extensions

  • Plugins — shell, filesystem, dialog, HTTP, SQL (sqlx), WebSocket (tokio-tungstenite), custom plugin development
  • Native and Mobile — iOS (WKWebView + Xcode), Android (WebView + Gradle), lifecycle, permissions, safe area

Cross-Cutting

  • Security, Performance, Patterns — CSP, ACL defense-in-depth, binary size, memory usage, IPC throughput, testing strategies, design patterns, common pitfalls, CI/CD
