AJ/DC -- Documentation Index

AJ/DC (Active Job Durable Continuation) is a Rails gem by Vladimir Dementyev that makes ActiveJob::Continuable jobs durable. The run and its steps are database rows, so progress survives a crash, a run can wait for a time or a signal without holding a worker, and every run is identified, queryable, and resumable.

These documents explain the whole gem, including its dependency ActiveJob::Continuable from Rails 8.1. Read them in order; each one builds on the last.

  2. 01-architecture.md -- one concern, one run record, one mediator: how ActiveJob::Durable, the Run/Step models, and the Execution mediator fit together.
  3. 02-continuable-foundation.md -- the dependency: ActiveJob::Continuable, the Continuation class, cursors, interrupts, and resumptions.
  4. 03-installation-and-setup.md -- two tables, one clock, one database decision: the generator, connects_to, and the recurring jobs.
  5. 04-data-model.md -- the schema, Run/Step models, and the StateType JSON serialization, column by column.
  6. 05-steps-cursors-checkpoints.md -- the step DSL, cursors, isolated steps, and how checkpoints commit progress.
  7. 06-run-lifecycle.md -- the nine statuses and the guarded, last-write-wins transitions between them.
