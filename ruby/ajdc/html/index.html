ajdc Documentation

Active Job Durable Continuation (AJ/DC) by Vladimir Dementyev. A Rails gem that makes ActiveJob::Continuable jobs durable: the run and its steps are database rows, so progress survives a crash, a run can wait for a time or a signal without holding a worker, and every run is identified, queryable, and resumable.
