anycable Documentation

AnyCable-Go: the Go implementation of the AnyCable WebSocket server. It speaks the AnyCable protocol (protobuf over WebSocket), keeps a hub of connections per stream, fans broadcasts out over NATS or Redis pub/sub, and embeds an mruby engine (mrb/) to run Rails-side Ruby code for RPC callbacks. Built for high throughput and low memory.
