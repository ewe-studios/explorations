logux Documentation

Logux: a JavaScript/TypeScript framework for client-server synchronization. Every change is an action appended to a shared, persistent, replicated log. Covers three core packages: logux-core (the action log, node primitives, and the Logux protocol), logux-server (the WebSocket server that syncs actions and tracks subscriptions), and logux-actions (built-in actions such as sync-map, processing, subscriptions, zero-knowledge, and crdt-table).
