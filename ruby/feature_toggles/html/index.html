feature_toggles Documentation

feature_toggles: a Ruby gem (Evil Martians) for pending features that take longer than a single release cycle. Features are declared in a Ruby DSL config file (env/feature methods evaluated via instance_eval), so a team can see at a glance what is pending, done, or stalled and gate code on the list. Small: a single entry point over a few classes.
