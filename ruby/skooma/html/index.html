skooma Documentation

Skooma: a Ruby library for validating API implementations against OpenAPI 3.1.0 documents. Each operation in an OpenAPI document carries a JSON Schema for its request and response; Skooma validates a real request or response body, headers, and parameters against that schema and returns the list of violations.
