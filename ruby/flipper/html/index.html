flipper Documentation

Flipper: beautiful, performant feature flags for Ruby and Rails. A feature flag is a boolean gate answered through a uniform API and stored by a pluggable adapter (memory, ActiveRecord, Redis, Sequel, Mongo, Moneta, Dalli, Rollout, cloud). Groups and percentage-of-actors rollouts build on top of the same gate. A monorepo of twelve gems.
