activejob Documentation

Ruby on Rails' ActiveJob: one job interface over many queue backends. A job is a Ruby object that is serialized (arguments via ActiveJob::Arguments, models via GlobalID), handed to a queue adapter, and later rebuilt and run. Covers the enqueue-to-perform lifecycle, adapters, callbacks, retry/discard, and the Continuable step machinery.
