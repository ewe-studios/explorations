usewinslow Documentation

An exploration of usewinslow.com — an artificial-intelligence-native payroll, benefits, and Human Resources Information System (HRIS) platform. The company makes one large claim: its whole product is reachable through a public Model Context Protocol (MCP) server, so a customer can build an application with an artificial-intelligence builder and install it into Winslow's own navigation. This set tests that claim against the public evidence.

Every factual claim traces to a page of the live website, to /winslow.md, or to an observed Hypertext Transfer Protocol (HTTP) request. When the public record does not answer a question, the text says so.
