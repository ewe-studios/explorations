What the MCP exploration answers

The Cloudflare MCP server exposes the whole Cloudflare API through a small set of tools. The main question is how a model can call thousands of API methods without loading thousands of tool definitions into its context.

The answer is code mode. The model writes code. The code runs in a sandbox. The sandbox sends API requests through a proxy that holds the user token. The model never sees the token, and the context holds a few tool descriptions instead of the full catalog.
