ai-iso-skill Documentation

iso-figure: a Claude skill (by MrBongoC/Tolga Cohce, MIT) that draws interactive isometric line-art figures. Name an object and get one self-contained HTML/SVG file: a hairline isometric drawing on a numbered plate with parts that work when pressed. About 15 lines of projection code, no libraries.
