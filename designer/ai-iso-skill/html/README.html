ai-iso-skill -- Index

iso-figure is a Claude skill by Tolga Cohce (MrBongoC). The user names an object. The skill has Claude produce one self-contained HyperText Markup Language (HTML) file: a hairline isometric line drawing on a numbered plate, with parts that work when pressed. No libraries, no canvas, no three-dimensional (3D) engine. About fifteen lines of JavaScript (JS) do the projection.

The key idea comes first in the skill file: the object must do something real. A figure that only animates is decoration. A figure where pressing a part produces output — typed text, a number, a note, a sound, a changed display — is the point. Every other rule serves that one.

The documents are ordered as a course. Start at 00 and follow the Continue to footer, or jump to any piece. Each document teaches its key idea in the first paragraph, shows the real code, and names the source file it reads.

What each file proves

SKILL.md is the specification. The two files under examples/ are real outputs that obey it. The calculator file shows typed text and arithmetic. The synthesizer file shows held instrument keys, drag across keys, and live sound. Both files embed the same projection kernel verbatim. The two files under docs/ are the moving previews used by the README.
