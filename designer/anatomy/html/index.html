anatomy Documentation

Anatomy: a Claude skill (by Ryan, MIT) for technical exploded-view figures of real objects. A kit of JavaScript modules (iso-kit, lathe, turn, tube, WebGL, canvas painter, React, PDF), nine references, many worked examples (raptor engine, ripple tank, turning dial, arcade cabinet), and a capture/verify/publish toolchain with an extensive test suite.
