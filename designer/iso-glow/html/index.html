iso-glow Documentation

ISO-GLOW: a Claude skill (by April Zhu, MIT) for interactive isometric line-art figures with glow lighting. A dark hairline drawing where only what is live glows in one accent colour, plus a palette picker, a gallery shell, a three.js 3D mode, and a solid lit Lumen style. Builds on iso-figure.

  • 00 -- Overview: a dark hairline drawing where only what is live glows
  • 01 -- The iso-figure base: nine lines of projection do all the drawing
  • 02 -- Glow lighting: one accent colour, only on what is live
  • 03 -- The palette picker: the accent is a CSS variable, so the picker is one selector
  • 04 -- The gallery shell: one api object and one mount function run the whole page
  • 05 -- 3D mode: the same hairline look rebuilt on three.js
  • 06 -- 3D figures: a registry turns modules into tabs, panels, and raycast clicks
  • 07 -- Lumen: the lit style is a shading kit, so the glow is geometry, not a filter
  • 08 -- Anatomy builds: a lens prescription drives a real cutaway
