charter Documentation

charter: contract-first APIs on Cloudflare Workers. One contract (Go/Huma or TypeScript/oRPC) becomes OpenAPI and AsyncAPI specs, Fern SDKs, MCP tools, auth, rate limits, and streaming; it builds, deploys and serves with no wrangler or Node, and a twin comparison holds the Go and TypeScript implementations to the same answers.
