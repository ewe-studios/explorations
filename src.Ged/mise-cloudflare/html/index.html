mise-cloudflare Documentation

mise-cloudflare: a mise backend plugin (Go) that turns a Cloudflare Worker repo into thirteen numbered mise tasks (03 through 15). No API tokens anywhere; one 'repo's own login' (a wrangler auth profile) bound to the folder; run locally, deploy, connect GitHub Workers Builds for previews/staging/production, and delete/clean that undo every step. The bridge never parses a wrangler config — it asks wrangler.
