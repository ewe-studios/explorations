Electric and Durable Streams

This exploration studies two repositories as one system:

  1. Electric at /Users/darkvoid/GitSources/src.Electric/electric (commit 3f9809fb0).
  2. Durable Streams at /Users/darkvoid/GitSources/src.Electric/durable-streams (commit 461b4026).

Electric Agents is a platform for durable artificial-intelligence agents. Each agent is an entity. Each entity owns one append-only event stream. Durable Streams stores and delivers that stream. The agent runtime writes events into the stream. A wake mechanism tells the runtime when to run the handler again.

The most important question in this exploration is: how does the runtime set up the durable stream, and where is that stream stored? Document 04-how-the-runtime-sets-up-a-stream.md answers that question in full.

The one-paragraph architecture

A user sends a message to an entity through the agents-server HTTP interface. The server writes an inbox event into the entity's stream. Durable Streams stores the event and notifies the entity's subscription. The subscription forwards a signed webhook to the agent runtime. The runtime reads the stream from its last acknowledged offset. It materializes the events into typed collections. It runs the entity handler. The handler writes new runs, steps, texts, and toolCalls events back into the same stream. The stream is the database, the message bus, and the audit log at the same time.
