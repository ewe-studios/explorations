walgit-celld-replication Documentation

walgit vs celld on S3: a comparative study of how two Deno-authored Rust systems replicate state to S3/GCS. walgit is a git server that treats the bucket as the repository (content-addressed objects, packs, a WAL, compare-and-swap keys, every machine a disposable cache); celld is a Durable Objects daemon that replicates each cell's SQLite state as LTX segments and fences ownership with compare-and-swap, gating every egress on a durability ticket for RPO=0. Side by side: the unit of state, the write path, consistency, and efficiency.
