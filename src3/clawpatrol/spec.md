## What clawpatrol Is

clawpatrol is an agent-security firewall written in Go. It sits between AI
agents and production systems, parses their network traffic at the wire, and
gates each action against rules written in HCL (HashiCorp Configuration
Language). An operator can block destructive SQL, pause `kubectl delete` for
human approval, and inject real credentials only at the gateway, so the agent
never sees them.

The project ships:

- a `gateway` binary that terminates TLS, parses HTTP, PostgreSQL, Kubernetes
  API, and SSH traffic, and enforces rules
- a plugin SDK (`pluginsdk/`) for out-of-process plugins
- a dashboard (TypeScript, embedded in the Go binary) for viewing actions,
  approving human-in-the-loop requests, and editing config
- three deployment shapes: `gateway` (proxy), `join` (WireGuard tunnel), and
  `run` (per-process network namespace)

## Quality Requirements (Iron Rules)

1. Every numbered doc starts with `# NN -- Title: subtitle` on line one. No
   frontmatter.
2. Every numbered doc has at least two Mermaid diagrams, each preceded by its
   own `%%{init: ...}%%` directive, all node labels quoted, no unquoted
   parentheses in labels.
3. Every numbered doc has at least three real code snippets, each fenced and
   attributed `// Source: path, lines N-M`. Snippets are verbatim.
4. Every numbered doc has exactly one `## The Aha Moment` section, first line
   bolded `**Aha:**`.
5. Every numbered doc has at least two cross-references.
6. Every numbered doc ends with `Continue to [NN-slug.md](NN-slug.md).`, chained
   00 through the last doc and then back to README. No orphan.
7. Prose follows ASD-STE100; abbreviations are spelled out at first use.
8. Every factual claim is verified against source. Where the docs and the code
   disagree, the code wins.
