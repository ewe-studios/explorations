clawpatrol Documentation

clawpatrol: an agent-security firewall (Go) that sits between agents and production, parses their traffic at the wire, and gates each action against rules written in HCL — for example blocking destructive SQL or pausing kubectl delete until a human approves. Ships a plugin SDK, a dashboard, and a gateway with brokered dials.
