clawpatrol-plugin-aws Documentation

clawpatrol-plugin-aws: an external clawpatrol plugin (Go) that gates AWS API calls across many accounts. Terminates TLS, parses each request into an aws facet for rule matching, selects the target account, assumes a per-account role with a single base key, re-signs with SigV4, and forwards to AWS through the gateway brokered dial.
