vnotify Documentation

vnotify: a lightweight Rust library (by the Deno authors) for monitoring S3 changes without external dependencies. Detects changes across millions of objects with one HeadObject and sometimes one ListObjectsV2 call by using a fixed-size S3 keyspace as a hash map to signal bucket-wide changes.
