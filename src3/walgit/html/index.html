walgit Documentation

walgit: a git server that is one binary in front of an object store (Rust). Hosts git repositories with no database, no leader, and no local state that matters — point it at an S3 or GCS bucket and get smart HTTP fetch and push, Git LFS, a web UI, a JSON API with an SDK, per-repository push policy, and webhooks. Every machine is a disposable cache; the bucket is the repository.
