DivKit Documentation

A deep documentation of DivKit, Yandex's Server-Driven UI framework: one JSON card renders as native views on iOS, Android, Web, and Flutter. The JSON schema is the single source of truth; a Python generator compiles it into the models four renderers read and the builders three server languages write. This index covers all 27 documents, from the card format to the layout engine to the production tooling.
