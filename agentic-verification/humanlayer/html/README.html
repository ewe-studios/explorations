HumanLayer Documentation

**HumanLayer runs coding agents (Claude Code, Codex, OpenCode, Pi) on your machines and lets your team steer them from one place.** A session is a database row. A daemon on the host is the remote hand that acts on it. An Electric sync plane is the shared eye that shows it to everyone. Electric is the sync engine. One oRPC (the procedure-call library) contract package is the spine that keeps the API, the daemon, the browser, and the desktop shells in agreement about the fields of that row. A second contract covers the desktop procedure calls.

The product names in that sentence differ from the schema values. The daemon launches Claude Code and CodeLayer. It runs Fold when the default-off experiment is on. It mirrors Codex, OpenCode, and Pi. The glossary maps each name to its coding-agent value and states whether the daemon can launch it (Glossary).

The one-paragraph thesis

HumanLayer works because it refuses to make the host a server. The daemon on a machine opens only outbound connections, so a laptop behind a home router is reachable without a port, a certificate, or a tunnel. Read authority flows the other way, through Electric, so every person sees the same rows without a custom push protocol. The cost of that choice is that the daemon must poll and subscribe for its instructions, and that the access rule lives in two places: SQL in the proxy and Drizzle in the API. This set explains the design, the code that implements it, and the places where the two halves can disagree.
