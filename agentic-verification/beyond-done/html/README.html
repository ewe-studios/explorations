Beyond Done Documentation

A 60-minute workshop that teaches artificial intelligence (AI) coding agents to verify their own work. An agent says "done"; give it a way to show the receipt.

This set explains the "beyond done" idea, the principles behind it, and exactly how the workshop's proof lever (pnpm snack), receipt, Jev judge, and bug game work. Every claim traces to a file in the repository workos/beyond-done (commit 51a1e36).
